# Distributed Flight System

A distributed system built with Kotlin and Spring Boot for managing flight bookings and operations.

## Tech Stack
- **Language:** Kotlin
- **Framework:** Spring Boot
- **Build Tool:** Gradle
- **JDK Version:** 17

## Prerequisites
- JDK 17 or higher
- Git

## How to Run

### On macOS / Linux:
```bash
# Make wrapper executable
chmod +x gradlew

# Build project
./gradlew build

# Run application
./gradlew bootRun
